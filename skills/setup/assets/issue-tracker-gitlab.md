# Issue tracker: GitLab

Issues for this project are managed as GitLab issues.

The issues live in the same remote as the source code (the GitLab default).

Use the `glab` CLI for all operations.

You can learn about the `glab` issue CLI with `glab issue --help`.

## Labels

The following issue labels are used:
```
Name           Color
<label>        <color>
<label>        <color>
```
