# Skills fetched from https://www.skills.sh into skills/.
#
# Format: <repository-url> <skill-name>
#
# `scripts/update_skills.py` fetches each entry with the skills.sh CLI
# (`skills add <repository-url> --skill <skill-name>`). The fetched
# directories ARE vendored in git: everything under skills/ is committed,
# so re-fetching shows up as a reviewable diff.
#
# Skills not listed here (1password, claude-history, python-knowledge-patch)
# are maintained by hand in this repository and the fetcher leaves them alone.
